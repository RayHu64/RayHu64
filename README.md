### 🎙️ Smart Speech-to-Video Learning Assistant
**Santa Clara University — Apr–May 2025**  
An end-to-end voice-driven recommendation system for non-native English learners.

- 🗣️ Integrated **speech recognition**, **keyword extraction (KeyBERT)**, and **YouTube API** into an automated pipeline.
- 🎧 Processed 250 accented audio samples (Common Voice dataset), applying MP3-to-WAV conversion, silence trimming, and segmentation.
- 🔧 Fine-tuned **NVIDIA NeMo QuartzNet** using **NovoGrad optimizer** with learning rate scheduling.
- 📉 Reduced **Word Error Rate (WER)** from 18.7% to **10.5%** (44% relative reduction).
- 📊 Benchmarked **Adam, SGD, NovoGrad** under multiple learning rates, demonstrating NovoGrad’s superior convergence.
